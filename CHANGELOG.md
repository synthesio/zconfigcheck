# Change Log
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## Unreleased
### Fixed
- issues reported by golangci-lint
- issues that appeared with golang.org/x/tools v0.25.0 in static.CallGraph

### Changed
- golangci-lint v2 is now used
- improved CI integration

### Added
- enabled dependabot
- zconfigcheck integration is now validated by GitHub Actions

## 0.2.0 - 2024-09-05
### Changed
- Target go 1.23.0 as minimum version
- Use `golang.org/x/exp/typeparams/GenericAssignableTo` instead of `types/AssignableTo`. This avoids skipping
  injection type checks when the source is generic and the destination is not
- Parse all structs generated by generic types instantiations. This allows listing issues when a generic type instance
  is used as the argument for `zconfig/Configure`

## 0.1.2 - 2024-07-11
### Fixed
- Do not call `DeleteSyntheticNodes` on the call graph, because it prevents discoverability of calls to zconfig
